// Changelog

On the record.

Every release of tractum since the first signed answer — Keep a Changelog format, newest first. The full diffs live on GitHub.

v0.5.0 2026-10-17 release notes →

claudeway → tractum. .curt linkage. Self-verifying MCP receipts.

  • The rename — package, module, CLI (tractum-mcp) and env vars (TRACTUM_*). Wire-format type tags stay claudeway.* so 0.2–0.4 receipts keep verifying.
  • .curt linkage — bind a signed receipt to .curt transcript evidence; the linkage hash lives inside the signed payload, so the aggregate signature covers it.
  • MCP always signs — ephemeral operator key by default; TRACTUM_REQUIRE_PINNED_KEY=1 to forbid it; TRACTUM_MCP_DRY_RUN=1 offline stub mode.
  • 227 tests; first .curt-native consumer (consensus-receipt extension).
v0.4.0 2026-10-01 release notes →

Per-agent signed statements + k-of-n quorum receipts.

  • Every agent signs its own stance — answer, confidence, model, role, task, round. The receipt becomes a countable multi-sig.
  • v2 receipt payload carries the statements plus a quorum threshold k (default: unanimous). v1 receipts verify forever.
  • verify_receipt_detailed — per-statement verdicts, cross-task replay detection, operator + per-agent key pinning.
  • New adversarial tests for the statement attack surface; honest threat-model note: a signature proves self-consistency, not key custody.
v0.3.2 2026-07-26 release notes →

  • OIDC trusted publishing — PyPI releases mint short-lived tokens; no long-lived API secrets on the repo.
  • Canonical OG image — social previews render the card instead of a blank tile.

v0.3.0 2026-07-25 release notes →

The coordination layer the frameworks punted on.

  • Signed multi-agent consensus with surfaced disagreement — WeightedVote + Debate, Ed25519 and ML-DSA-65 backends, RFC 6962 transparency log, three transports.
  • Benchmark: +7/20 over a single Claude call on hard questions.
  • First signed consensus live on Nostr — NIP-78 event, five public relays, verifiable by anyone.
v0.2.0 2026-07-25 release notes →
